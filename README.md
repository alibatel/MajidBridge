# 🌉 MajidBridge v2 — مرورگر ابری شخصی

یک مرورگر Chromium واقعی روی سرور که از داخل مرورگر خودت می‌بینی و کنترلش می‌کنی: آدرس بزن، کلیک کن، تایپ کن (فارسی هم)، اسکرول کن، زوم کن، کپی/پیست کن. همه‌ی سایت‌ها **IP سرور** را می‌بینند، نه IP تو را.

## ✨ چه چیزهایی در v2 اضافه شد

| قابلیت | توضیح |
|---|---|
| 🛡️ **Stealth ضدشناسایی** | `navigator.webdriver` حذف، `plugins`/`mimeTypes`/`permissions`/WebGL/`window.chrome` واقعی، UA و UA-Client-Hints مطابق Chrome ویندوز، `--disable-blink-features=AutomationControlled` → برای رد شدن از تیک امنیتی Cloudflare (مثل ChatGPT) |
| 🖥️ **حالت HEADFUL روی Xvfb** | با `HEADFUL=true` مرورگر **با پنجره‌ی واقعی** روی نمایش مجازی اجرا می‌شود (قوی‌ترین راه ضدشناسایی). Xvfb داخل Dockerfile نصب است |
| 🕘 **تب تاریخچه** | تاریخچه‌ی ناوبری با زمان، کلیک روی هر مورد = رفتن به آن، امکان پاک کردن — ذخیره روی دیسک |
| ⭐ **تب نشان‌ها** | افزودن/حذف نشان (Bookmark) با دکمه‌ی ☆ — ذخیره روی دیسک |
| ⚙️ **تب تنظیمات** | کیفیت تصویر، وضوح صفحه، زوم، همگام‌سازی کلیپبورد، صفحه‌ی شروع |
| 📋 **کلیپبورد دوطرفه** | `Ctrl+C` روی صفحه‌ی سرور → متن در کلیپبورد مرورگر تو می‌نشیند؛ `Ctrl+V` → متن تو در صفحه‌ی سرور چسبانده می‌شود (دو مسیر: Clipboard API + پل رویداد `copy`) |
| 💾 **پروفایل ماندگار** | `launchPersistentContext` روی `/data/profile/userdata` → کوکی‌ها و لاگین‌ها بعد از Redeploy/ری‌استارت می‌مانند |
| 🔍 **زوم زنده** | از ۵۰٪ تا ۲۵۰٪ با دکمه، اسلایدر، `Ctrl+±`، `Ctrl+0` و `Ctrl+چرخ موس` (CDP `setPageScaleFactor`) |
| 📐 **تغییر وضوح زنده** | بدون ری‌استارت: پیش‌فرض‌ها (۱۹۲۰×۱۰۸۰ … ۸۰۰×۶۰۰)، وضوح دلخواه، یا حالت «خودکار» که با اندازه‌ی پنجره‌ی تو عوض می‌شود |

## 🚀 اجرای سریع

### روی hostim (پیشنهادی)
1. این ریپو را به hostim بده (Deploy from Git) — خودش از `Dockerfile` می‌سازد.
2. متغیر محیطی `PASSWORD` را ست کن (رمز ورود — خیلی مهم چون آدرس عمومی است).
3. **برای ماندن لاگین‌ها:** یک دیسک/Volume به مسیر `/data` وصل کن.
4. Deploy کن و آدرسی که داد (مثل `xxx.hostim.dev`) را در مرورگرت باز کن.

| متغیر | لازم؟ | پیش‌فرض | توضیح |
|---|---|---|---|
| `PASSWORD` | ✅ بله | خالی | رمز ورود به مرورگر ابری |
| `QUALITY` | نه | `medium` | کیفیت تصویر: `low` / `medium` / `high` |
| `START_URL` | نه | `https://example.com` | صفحه‌ی شروع |
| `VIEWPORT_W` / `VIEWPORT_H` | نه | `1280` / `800` | اندازه‌ی صفحه سرور (زنده هم عوض می‌شود) |
| `ZOOM` | نه | `1` | زوم پیش‌فرض (۰.۵ تا ۳) |
| `HEADFUL` | نه | `false` | `true` = اجرای با پنجره روی Xvfb (ضدشناسایی قوی‌تر، رم بیشتر) |
| `PROFILE_DIR` | نه | `/data/profile` | پوشه‌ی پروفایل ماندگار |
| `ALLOW_EVAL` | ❌ هرگز در محصول | `false` | فقط برای تست خودکار |
| `MOCK_BROWSER` | ❌ هرگز در محصول | `false` | فقط برای تست بدون Chromium |

حداقل رم: حدود **۱ گیگ** برای headless و **۱.۵–۲ گیگ** برای `HEADFUL=true`.

### روی کامپیوتر خودت (تست)
```bash
docker compose up --build
# بعد باز کن: http://localhost:3000
```

### بدون داکر
```bash
npm install
npx playwright install --with-deps chromium
PASSWORD=mypass node server.js          # حالت عادی
PASSWORD=mypass HEADFUL=true npm start  # حالت headful (روی لینوکس باید Xvfb داشته باشی)
```

## 🧪 تست خودکار (۱۵ تست)
```bash
ALLOW_EVAL=true PASSWORD=testpass node server.js   # ترمینال ۱
PASSWORD=testpass npm test                         # ترمینال ۲
```
روی سیستمی که Chromium ندارد (تست کامل پروتکل و رابط با مرورگر مجازی — ۱۵ تست):
```bash
MOCK_BROWSER=true ALLOW_EVAL=true PASSWORD=testpass node server.js
PASSWORD=testpass npm test
```
تست‌ها: سلامت سرور، رابط وب، وب‌سوکت، `hello`، احراز هویت، ناوبری، فریم JPEG زنده، کلیک+تایپ فارسی، اسکرول/عقب/جلو، کیفیت، وضوح زنده، زوم، تاریخچه، نشان‌ها، کلیپبورد دوطرفه و (+سایت عمومی واقعی وقتی اینترنت هست).

## ⚙️ معماری (خلاصه)
- `Node.js` + `Playwright` + `Chromium` + `WebSocket` + `Express`
- تصویر زنده: **CDP Screencast** (فقط وقتی صفحه عوض شود فریم JPEG می‌فرستد → مصرف کم وقتی داری متن می‌خوانی) با حالت جایگزین اسکرین‌شات دوره‌ای.
- ورودی: مختصات موس روی عکس به مختصات واقعی سرور تبدیل و با Playwright اجرا می‌شود؛ تایپ با `keyboard.type` (پشتیبانی کامل فارسی).
- داده‌های ماندگار (تاریخچه/نشان‌ها/تنظیمات) به‌صورت JSON ساده در `PROFILE_DIR` (یا `.data/`) ذخیره می‌شوند — بدون وابستگی اضافه.
- تک‌پورت (پیش‌فرض `3000`) و تک‌کانتینر — مناسب PaaS مثل hostim.

## 🛡️ اگر تیک امنیتی Cloudflare باز هم کار نکرد
1. در hostim متغیر `HEADFUL=true` را ست کن و **Redeploy** بزن.
2. پلن را ارتقا بده (مثلاً `sa-2-2`) چون حالت headful رم و CPU بیشتری می‌خواهد.
3. مطمئن شو `/data` یک Volume ماندگار است تا لاگین‌ها نپرند.
4. کیفیت را روی `low` بگذار تا پهنای باند کمتر مصرف شود.

## ⚠️ محدودیت‌ها
- فیلم روان و صدا ندارد (عکس پشت سر هم است) — برای وب‌گردی عادی عالی است.
- کمی تأخیر (~نیم ثانیه) دارد.
- تک‌کاربره است (همه‌ی وصل‌شونده‌ها همان یک صفحه را می‌بینند).
- کلیپبورد مرورگر کاربر فقط در صفحه‌ی **HTTPS** یا `localhost` در دسترس است؛ در غیر این صورت یک پنجره‌ی کوچک برای paste باز می‌شود.
